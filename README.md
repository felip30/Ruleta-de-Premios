## 📌 ¿Como Funciona?
- Se inicia el proceso
- Se declara una variable “premio” para almacenar el resultado.
- Se crea una lista con los posibles premios.
- Se imprime un mensaje indicado que se esta girando la ruleta
- Se utiliza la función “Aleatorio (1,5)” para seleccionar un premio al azar de la lista
- Se imprime el premio que ha ganado el usuario
- Se indica el final del proceso
